# se-pov-builder (backend)

FastAPI backend for the SE Demo & POV Builder. See the tool README one directory up for
installation, configuration and usage.

```bash
python -m se_pov_builder                   # run the API (127.0.0.1:8000)
python -m se_pov_builder.validate_content  # validate YAML content
pytest                                     # run tests (from this directory)
```
